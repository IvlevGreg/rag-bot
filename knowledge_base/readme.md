# Инструкция по пользования базой знаний

## Get started

Установить npm/node.js + yarn

запустить скрипт
``` bash
yarn
``` 

## Работа с базой
1. Добавить новые текстовые файлы

2. Извлечение чистого текста
Скрипт processFiles.js копирует файлы из original_files и сохраняет очищенный текст
в папку processed_files/ (с сохранением подпапок, меняет расширение на .txt).

``` bash
yarn processFiles
```
3. Поиск топ-50 терминов и обновить (если необходимо)
Скрипт find_star_terms.js ищет 50 самых частых терминов (например, имена, названия, расы)
в уже очищенных текстах из папки processed_files.

При запуске скрипт создаёт файл terms_map_draft_with_comments.js
в котором содержится объект из 50 обнаруженных терминов, случайных имён-замен и комментариев (количество вхождений и вложенности терминов),

``` bash
yarn findStarTerms
```
Скрипт для удаления комментов в файле terms_map_draft_with_comments и дальнейшей замены  

``` bash
yarn removeComments
```


4. Заменить термины в текстах (по terms_map.json)
Скрипт replaceTerms.js заменяет термины в текстах по словарю (terms_map.json) во всех подходящих файлах папки.

``` bash
yarn replaceTerms
```

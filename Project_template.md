## Задание 1. Исследование моделей и инфраструктуры

### **1. Сравнение LLM-моделей**

| Критерий             | Локальные (Hugging Face)                                         | Облачные (OpenAI/YandexGPT)             |
|----------------------|------------------------------------------------------------------|-----------------------------------------|
| **Качество ответов** | Среднее-высокое (зависит от модели, e.g., Llama 3 70B ≈ GPT-3.5) | Высокое (GPT-4-turbo, YandexGPT 2.0)    |
| **Скорость работы**  | 0.5-5 сек/запрос (зависит от GPU/CPU)                            | 1-3 сек/запрос (сетевая задержка)       |
| **Стоимость**        | Капитальные затраты (GPU $5k-$15k), электроэнергия               | Операционные ($0.01-$0.1/запрос)        |
| **Удобство**         | Сложное развёртывание, требуется ML-инфраструктура               | Простое API, мгновенное масштабирование |

**Для QuantumForge**:  
Облачные решения предпочтительны для скорости и простоты, но локальные модели (e.g., Mistral 7B) стоит рассмотреть для конфиденциальных данных.

### **2. Сравнение моделей эмбеддингов**

| Критерий                | Локальные (Sentence-Transformers)        | Облачные (OpenAI Embeddings)          |
|-------------------------|------------------------------------------|---------------------------------------|
| **Скорость индексации** | 10-100 сек/документ (зависит от CPU/GPU) | 1-5 сек/документ (но лимиты API)      |
| **Качество поиска**     | Высокое (e.g., all-MiniLM-L6-v2)         | Максимальное (text-embedding-3-large) |
| **Стоимость**           | Бесплатно                                | $0.10-$0.80/1M токенов                |
| **Конфиденциальность**  | Данные остаются локально                 | Данные передаются в облако            |

**Для QuantumForge**:  
Локальные эмбеддинги оптимальны из-за конфиденциальности данных и отсутствия эксплуатационных расходов.

### **3. Сравнение векторных баз**

| Критерий                | ChromaDB                                  | FAISS                                     |
|-------------------------|-------------------------------------------|-------------------------------------------|
| **Скорость поиска**     | 10-50 мс/запрос                           | 1-10 мс/запрос                            |
| **Сложность поддержки** | Низкая (встроенный сервер, Python API)    | Средняя (требует обёрток для продакшена)  |
| **Удобство**            | Автоматическое управление метаданными     | Ручное управление индексами               |
| **Стоимость владения**  | Бесплатно, требует 2-4 ГБ RAM/1M векторов | Бесплатно, требует 1-2 ГБ RAM/1M векторов |

**Для QuantumForge**:  
ChromaDB предпочтительна из-за удобства работы с метаданными (Confluence/Zendesk), FAISS — для максимальной скорости.

### **4. Рекомендуемая конфигурация сервера**

| Компонент | Рекомендация                 | Обоснование                                   |
|-----------|------------------------------|-----------------------------------------------|
| **CPU**   | 8 ядер (Intel Xeon/AMD EPYC) | Обработка эмбеддингов и параллельных запросов |
| **RAM**   | 32 ГБ                        | Для индекса 50k+ документов в памяти          |
| **GPU**   | NVIDIA RTX 4090 (24 ГБ)      | Ускорение локальных LLM (опционально)         |
| **Диск**  | 500 ГБ SSD NVMe              | Хранение индексов и логов                     |

**Оценка нагрузки**:
- 18k документов → ~5 ГБ для индексов FAISS/ChromaDB.
- 100 одновременных пользователей → 4 ГБ RAM.

#### **Выбор инструментов и инфраструктуры:**

| Параметр           | Вариант 1 (Локальный стек)          | Вариант 2 (Гибридный)        | Вариант 3 (Облачный)      |
|--------------------|-------------------------------------|------------------------------|---------------------------|
| **LLM**            | Hugging Face (Mistral 7B)           | YandexGPT 2.0 (API)          | OpenAI GPT-4-turbo        |
| **Эмбеддинги**     | all-MiniLM-L6-v2                    | e5-base-v2 (локально)        | text-embedding-3-small    |
| **Векторная БД**   | ChromaDB                            | ChromaDB                     | Pinecone                  |
| **Инфраструктура** | Сервер 8CPU/32GB RAM                | Yandex Cloud 4vCPU/16GB RAM  | AWS EC2 (c6g.xlarge)      |
| **Плюсы**          | Полная конфиденциальность, нет OPEX | Простота, GPT-ответы в API   | Качество, масштабирование |
| **Минусы**         | Инжиниринг, сложность               | API-зависимость, network lag | Дороговизна, data privacy |
| **Стоимость**      | $8k–$12k (one-time)                 | $500–$800/мес                | $1.5k–$3k/мес             |


Итоговая рекомендация вариант 2: гибрид (локальные эмбеддинги + облачная LLM) так как:
- Защищает корпоративную информацию (база знаний не покидает perimiter компании).
- Даёт отличное качество генерации ответов пользователям (OpenAI/YandexGPT — SOTA).
- Стоимость: Экономия до половины от облачного варианта
